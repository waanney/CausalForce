# CausalForce pipeline audit

Baseline commit: `78411bb855160229d0afc066e9d122970d295e55`

Working branch: `fix/causalforce-pipeline`

This audit distinguishes code-proven defects from checks that require the
server datasets/checkpoints. Local execution is unavailable because the local
shell has no Python runtime.

## Root causes and ranking

### P0 — Stage 1 checkpoint used for final Risk Tube metrics

`scripts/convergence/eval_paper_metrics.slurm` pointed to
`log/risk_category_classifier/epoch=9-last.ckpt` and called `inference.py`.
The classifier architecture has no `score_head`. `inference.py` created a model
with a new random `score_head` and accepted the missing weights via
`strict=False`. Thus the category head could retain 95.6% accuracy while the
Risk Tube was generated by untrained risk-score weights. This directly matches
the observed failure pattern.

Fix: paper metrics now require a calibrated Stage 2 checkpoint and causal
evaluator. All inference checkpoint loads reject missing/unexpected keys and a
missing `saocp_class` state.

### P0 — Risk category labels could be paired with the wrong object

The baseline constructed `label_risk_type` in bbox/category traversal order,
but training/evaluation selected it using the index of an object ID in the
independently ordered `risk_interval_H8` dictionary. The fix constructs an
object-ID-to-category map and emits labels in exactly the interval key order.

### P1 — SAOCP state mixed changing models and data populations

The same state was updated during every training batch and every validation
epoch while model weights changed. Training targeted coverage 0.7 even though
the evaluation path declared 0.9. The fix performs no training updates, resets
state for each fixed-model validation stream, defaults to 0.9, and refuses
unsynchronized multi-rank calibration. Empty class/horizon buckets now fail.

### P1 — Stage 1 to Stage 2 transfer was unchecked

`strict=False` hid arbitrary missing/unexpected keys. Transfer now has explicit
allow-lists and required shared prefixes, plus loaded/missing/unexpected and
frozen/trainable parameter reports.

### P1 — Stage 1 metric population was ambiguous

The reported 4,649 value counted sliding windows with at least one matched risk
object. Accuracy was averaged per window. OBS/OCC/I/C counts covered every
visible object slot in those windows, including non-risk objects and repeated
observations, so their sum can exceed 4,649. New reporting separates all three
populations and provides object-level metrics.

### P1 — HTSC used inconsistent object slots and an incomplete formula

The baseline indexed adjacent-frame features without consistently mapping
object IDs and omitted the second temporal term described by its own loss.
The fix maps each frame by object ID, compares only trackable same-class pairs,
and returns a differentiable zero when no pair exists.

### P2 — Tensor/device and padding correctness

Models trusted a caller-provided device string, built CPU masks in GPU paths,
and did not assert the hard-coded three-frame topology. Device follows input,
IDs are truncated with the same 12-slot boundary as bboxes, shapes are asserted,
and orthogonality excludes padding.

### P1 remaining — temporal LSTM slots may not preserve identity

The dataset orders objects independently in each frame, while the LSTM evolves
hidden state by slot. HTSC now maps IDs when computing its loss, but the LSTM
itself still assumes stable slot ordering. The server audit must measure ID
slot changes before any architectural/data-layout correction is authorized.

### P3 uncommitted — causal risk fusion redesign

An architectural change from a learned fusion output to a direct/indirect gate
was already present in the worktree before this audit. It is deliberately not
part of the correctness commits and requires a separately trained compatible
checkpoint and ablation.

## Metric semantics

- Coverage is `all(pred[gt == 1] == 1)`, i.e. the GT positive set is contained
  in the prediction. Empty GT objects are excluded from the risk-object metric.
- IoU is binary intersection over union and is exactly one for identical masks.
- TC is one minus the normalized absolute difference in switch counts.
- BA is the mean of exponentially weighted detection and release agreement.
- Per object, `Risk-IoU = IoU * (TC + BA) / 2`; the evaluator then averages.
  Consequently mean Risk-IoU need not equal the product of aggregate means.
- A fragmented sequence such as `0 1 0 1 1 0 0 0` remains fragmented for all
  metrics. Its debug envelope is `[1,4]`; no morphological filling occurs.
